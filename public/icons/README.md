# App Icons

This folder should contain your PWA app icons.

## Required Icons:

1. **icon-192x192.png** - 192x192 pixels
2. **icon-512x512.png** - 512x512 pixels

## How to Create Icons:

### Option 1: Use a Logo Generator
- Visit [https://www.canva.com/](https://www.canva.com/)
- Create a 512x512px design
- Add your logo/text (e.g., "JOB AGENT PH")
- Use blue theme colors (#2563eb)
- Export as PNG

### Option 2: Use Icon Generator Tools
- Visit [https://realfavicongenerator.net/](https://realfavicongenerator.net/)
- Upload your logo
- Generate all icon sizes
- Download and place in this folder

### Option 3: Simple Placeholder (Temporary)
For now, you can use a simple colored square:
- Create a 512x512px image with blue background (#2563eb)
- Add white text "JOB AGENT PH"
- Save as icon-512x512.png
- Resize to 192x192px and save as icon-192x192.png

## Recommended Design:

- **Background**: Blue gradient (#2563eb to #1d4ed8)
- **Icon**: Briefcase or plane symbol (represents jobs abroad)
- **Text**: "JOB AGENT PH" or "JAPH"
- **Style**: Modern, clean, professional

## Tools:

- [Figma](https://www.figma.com/) - Free design tool
- [Canva](https://www.canva.com/) - Easy design tool
- [GIMP](https://www.gimp.org/) - Free Photoshop alternative
- [Photopea](https://www.photopea.com/) - Online Photoshop alternative

---

**Note**: These icons will appear when users install your PWA on their phone/desktop.
