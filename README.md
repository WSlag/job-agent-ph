# 💼 JobAgent PH – Job Marketplace Platform

## 🚀 Production Platform

A job marketplace platform connecting Filipino professionals with employment opportunities locally and abroad.

Designed to digitize recruitment workflows and simplify job applications.

---

## 🧠 Business Context

Recruitment often relies on:

- Manual tracking  
- Messaging apps (FB, WhatsApp)  
- Disconnected workflows  

👉 This platform provides a centralized system.

---

## 💡 Features

### 👨‍💼 For Job Seekers

- Browse jobs  
- Apply with resume  
- Track applications  
- Message employers  

### 🏢 For Agencies

- Post jobs  
- Manage applications  
- Communicate with candidates  
- Track hiring  

---

## ⚙️ Tech Stack

- Next.js (React + TypeScript)  
- Firebase (Auth, Firestore, Storage)  
- Tailwind CSS  

---

## 🏗 System Capabilities

This platform demonstrates:

- Marketplace system design  
- Recruitment workflow automation  
- Real-time application tracking  
- Role-based access control  
- Cloud-based architecture
