# 📱 How to Install Job Agent PH as an App

## Why Install?

Installing Job Agent PH as an app gives you:

✅ **One-tap access** - App icon on your home screen
✅ **Faster loading** - Instant access from cached content
✅ **Works offline** - Browse jobs even without internet
✅ **Full screen** - No browser bars, more screen space
✅ **Stay updated** - Automatic updates in the background

---

## 🖥️ Desktop Installation (Windows, Mac, Linux)

### Chrome & Edge

**Method 1: Install Button (Recommended)**

1. Visit **www.jobagentph.com**
2. Look for the **"Install App"** button in the header
3. Click **"Install App"**
4. Click **"Install"** in the popup
5. Done! The app opens in a new window

**Method 2: Browser Menu**

1. Visit **www.jobagentph.com**
2. Click the **install icon** (⊕) in the address bar (right side)
3. Click **"Install"**
4. Done! The app opens automatically

**Method 3: Browser Settings**

1. Visit **www.jobagentph.com**
2. Click the **menu** (⋮) in the browser
3. Select **"Install Job Agent PH"** or **"Apps" → "Install this site as an app"**
4. Click **"Install"**

**Uninstall:**
- Right-click the app icon → "Uninstall" or "Remove"
- Or: Settings → Apps → Job Agent PH → Uninstall

---

## 📱 Android Installation

### Chrome (Recommended)

**Method 1: Install Banner (Automatic)**

1. Open **Chrome** on your Android device
2. Visit **www.jobagentph.com**
3. Browse the site for ~30 seconds
4. A banner appears at the bottom: **"Install Job Agent PH"**
5. Tap **"Install"**
6. The app icon appears on your home screen

**Method 2: Install Button**

1. Visit **www.jobagentph.com** in Chrome
2. Tap the **"Install App"** button in the header
3. Tap **"Install"** in the popup
4. Done! App icon added to home screen

**Method 3: Browser Menu**

1. Visit **www.jobagentph.com** in Chrome
2. Tap the **menu** (⋮) in the top-right
3. Tap **"Install app"** or **"Add to Home screen"**
4. Tap **"Install"** or **"Add"**
5. The app icon appears on your home screen

**Launching the App:**
- Tap the **Job Agent PH** icon on your home screen
- The app opens in full-screen mode (no browser bars)

**Uninstall:**
- Long-press the app icon → "Uninstall" or "Remove"
- Or: Settings → Apps → Job Agent PH → Uninstall

## 📱 iOS Installation (iPhone & iPad)

### Safari (Required)

⚠️ **Note:** You must use Safari browser on iOS. Chrome and other browsers don't support app installation on iOS.

**Steps:**

1. Open **Safari** on your iPhone or iPad
2. Visit **www.jobagentph.com**
3. Tap the **Share button** (square with arrow pointing up) at the bottom
4. Scroll down and tap **"Add to Home Screen"**
5. (Optional) Edit the name if desired
6. Tap **"Add"** in the top-right
7. Done! The app icon appears on your home screen

**Alternative (Guided):**

1. Visit **www.jobagentph.com** in Safari
2. A modal may appear with installation instructions
3. Follow the step-by-step guide shown in the modal

**Launching the App:**
- Tap the **Job Agent PH** icon on your home screen
- The app opens in standalone mode

**Removing the App:**
- Long-press the app icon
- Tap **"Remove App"** → **"Delete App"**
- Confirm deletion

## ❓ Frequently Asked Questions

### Does the app take up a lot of space?

No! The PWA (Progressive Web App) is very lightweight:
- **Initial install:** ~10-15 MB
- **With cache:** ~15-20 MB total
- Much smaller than native apps (typically 50-100 MB)

### Does it work offline?

Yes! Once installed:
- **Previously viewed pages:** Work fully offline
- **New pages:** Require internet connection
- **Offline message:** Friendly notification when you're offline

### Do I need to update the app?

No manual updates needed! The app updates automatically in the background when we release new versions. Just keep using it normally.

### Will it use my mobile data?

The app is optimized to minimize data usage:
- **First visit:** Downloads necessary files
- **Return visits:** Uses cached content (no data used)
- **Images:** Cached after first view
- **Updates:** Only downloads changes, not the entire app

### Can I use it on multiple devices?

Yes! Install the app on as many devices as you want:
- Desktop computer (Windows, Mac, Linux)
- Android phone or tablet
- iPhone or iPad
- All devices stay synced through your account

### How do I know it's installed correctly?

After installation:
- ✅ App icon appears on home screen
- ✅ Opens in full-screen (no browser bars)
- ✅ Loads instantly from cache
- ✅ Shows "Install App" button as "Installed" on website

### What if I don't see the install option?

**Desktop (Chrome/Edge):**
- Make sure you're using the latest version
- Try visiting the site again
- Check for an install icon in the address bar

**Android:**
- Make sure you're using Chrome (not Firefox or other browsers)
- Update Chrome to the latest version
- Wait ~30 seconds or browse 3+ pages
- Look for the banner at the bottom

**iOS:**
- Make sure you're using Safari (required for iOS)
- Use the Share button → "Add to Home Screen"
- If you don't see the option, make sure you're on iOS 13+

### Can I access my account on both web and app?

Yes! The installed app and web browser version share the same account:
- Log in once, access from anywhere
- Bookmarked jobs sync automatically
- Applications sync across devices
- Messages available on all platforms

### Is it safe to install?

Absolutely! The app is:
- ✅ Official Job Agent PH application
- ✅ Runs from our secure website (HTTPS)
- ✅ No special permissions required
- ✅ Same security as using the website
- ✅ Can be uninstalled anytime

## 🆘 Troubleshooting

### The install button doesn't appear

**Possible causes:**
- Browser doesn't support PWA installation
- Using an old browser version
- Already installed (check home screen)
- Not using HTTPS (should be automatic on jobagentph.com)

**Solutions:**
1. Try using **Chrome or Edge** (best support)
2. Update your browser to the latest version
3. Check if app is already installed
4. Clear browser cache and try again
5. Try the browser menu method instead

### The banner doesn't show up

The banner shows after you engage with the site:
- **Time:** After 30 seconds on the site
- **OR Pages:** After viewing 3+ different pages

If it still doesn't appear:
- You may have dismissed it previously (wait 7 days)
- Use the "Install App" button in the header instead
- Use the browser menu method

### The app icon looks wrong

On Android, try:
1. Uninstall the app
2. Clear browser cache
3. Reinstall the app
4. The correct icon should appear

### The app doesn't open

Try:
1. Uninstall the app
2. Restart your device
3. Reinstall the app
4. If issue persists, use the website instead

### Offline mode isn't working

**Note:** Only previously visited pages work offline.

To enable offline access:
1. Visit the pages you want to access offline while online
2. The pages are automatically cached
3. Next time you're offline, those pages will load

New pages require an internet connection.
